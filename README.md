# Call & Time

Static, browser-based call and attendance log website.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `call-time-office-desk` under `paulblue56`.
2. Upload the contents of this folder to the repository's `main` branch. Include `.github/workflows/deploy.yml` and `.nojekyll`.
3. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
4. Open the **Actions** tab and wait for **Deploy static website to GitHub Pages** to finish.
5. GitHub will show the website URL in the workflow deployment summary. It will normally be `https://paulblue56.github.io/call-time-office-desk/`.

The website saves its data in each browser's local storage. Hosting gives it a web URL but does not synchronize records between browsers or devices. No client or staff directory data is included in this repository.
